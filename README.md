# EASY-VISA-Machine-Learning-2-
EASY VISA 
Machine Learning 2 
In FY 2016, the OFLC processed 775,979 employer applications for 
over 1.69 million positions, marking a 9% increase from the previous 
year. With the continuous rise in applications, manually reviewing 
each case has become increasingly challenging. 
To address this issue, the OFLC has engaged EasyVisa, a data-driven 
consulting firm, to develop a Machine Learning-based solution that 
can: 
• Automate the visa approval screening process by identifying 
candidates with higher chances of approval. 
• Analyze key factors influencing visa approvals, such as 
education level, job experience, and prevailing wage. 
• Recommend a suitable applicant profile based on the factors 
that significantly impact case status (certified or denied). 
By leveraging machine learning, this solution aims to optimize the 
visa application process, reduce manual workload, and ensure fair 
and efficient decision-making.
